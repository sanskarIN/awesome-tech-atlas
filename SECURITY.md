# Security reporting

Awesome Tech Atlas primarily contains documentation, metadata, and lightweight repository validation scripts. It is **not a security certification** of listed third-party resources.

- Vulnerability in a **third-party project**: follow that project's official security disclosure instructions.
- Vulnerability in **this repository's scripts or workflows**: use GitHub's private vulnerability reporting feature **if enabled**, or privately contact the maintainer through their [GitHub profile](https://github.com/sanskarIN).
- Please do not post proof-of-concept exploits, sensitive keys, or personal data in public issues.

There is no guaranteed response time or bug-bounty program. Avoid including credentials in reports.
