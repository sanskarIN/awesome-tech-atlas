# Programming languages

Language syntax, runtimes, and practical introductions.

These are starting points, not an exhaustive list. Explore each profile for a practical first step, a limitation, and an alternative.

- **[Python documentation](../resources/python.md):** Upstream tutorial, language reference, and standard-library documentation for Python.
- **[The Rust Programming Language](../resources/rust.md):** The official Rust book explains ownership, borrowing, types, error handling, and application development.
- **[TypeScript documentation](../resources/typescript.md):** Official TypeScript handbook and references for a JavaScript type-checking language and toolchain.
- **[MDN JavaScript](../resources/javascript-mdn.md):** MDN's JavaScript guide and reference explain language syntax, built-in objects, and browser-oriented examples.

- **[Microsoft C language documentation](../resources/c-msvc.md):** Vendor documentation for C declarations, functions, expressions, implementation behavior and the Microsoft C runtime.

- **[Microsoft C++ documentation](../resources/cpp-msvc.md):** Vendor C++ reference linking language constructs, standard library usage, compiler options and native build tooling.

- **[Dev.java learning tutorials](../resources/java-dev.md):** Java learning portal covering language fundamentals, collections, runtime tools and application organization.

- **[Go documentation](../resources/go-docs.md):** Official Go documentation spanning introductory tutorials, language rules, dependency management, testing and runtime diagnostics.

- **[Kotlin basic syntax documentation](../resources/kotlin-basic.md):** Upstream syntax guide introducing Kotlin functions, variables, control flow, collections and nullable types.
