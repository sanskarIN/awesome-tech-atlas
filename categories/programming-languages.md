- **[The Rust Programming Language](../resources/rust.md):** The official Rust book explains ownership, borrowing, types, error handling, and application development.
- **[TypeScript documentation](../resources/typescript.md):** Official TypeScript handbook and references for a JavaScript type-checking language and toolchain.
- **[MDN JavaScript](../resources/javascript-mdn.md):** MDN's JavaScript guide and reference explain language syntax, built-in objects, and browser-oriented examples.
