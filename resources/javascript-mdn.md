## Why it matters

MDN's JavaScript guide and reference explain language syntax, built-in objects, and browser-oriented examples.

## Good fit

Learning core JavaScript concepts before choosing a framework.

## Strength and trade-off

- **Strength:** A searchable guide and language reference support both new learners and experienced developers.
- **Limitation:** Browser APIs and JavaScript language features are related but distinct; examples may assume a browser.

These are contextual selection notes, **not** independent speed, reliability, or security benchmarks.

## Try it

Open your browser developer console and evaluate `const double = n => n * 2; double(5)`.
