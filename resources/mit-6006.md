## Why it matters

Algorithmic reasoning requires more than recognizing a familiar code pattern. This course connects computational models, data structures, correctness arguments and performance analysis.

## Good fit

Learners comfortable with elementary programming and discrete mathematical reasoning who want a structured introduction to algorithm design.

## Strength and trade-off

- **Strength:** Lecture materials, exercises and assessment materials support active practice and mathematical justification.
- **Limitation:** The published material is a Spring 2020 course snapshot; self-learners must supply their own feedback and should not assume enrollment or academic credit.

These are contextual selection notes, not independently measured performance or reliability claims.

## Try it

Choose the first lecture and attempt an accompanying practice problem before reading any solution. Implement linear search on an array, write its invariant, count comparisons for a missing target and contrast that with binary search on sorted data. Record the sorting assumption explicitly.
